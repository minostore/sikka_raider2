# تطبيق مشوار — الراكب (Flutter: Android + iOS)

تطبيق طلب الرحلات بنظام عروض الأسعار (مثل inDrive): خريطة حقيقية بـ OpenStreetMap، موقع GPS حقيقي، بحث عناوين (Nominatim)، حساب المسافة والزمن ورسم الطريق (OSRM)، تتبع السائق لحظياً عبر Firebase Realtime Database. **بدون Google Maps وبدون Google Billing.**

## المميزات
- تسجيل/دخول بالجوال وكلمة المرور (Firebase Auth) — شاشات: البداية، الترحيب، الدخول، إنشاء حساب
- الرئيسية: خريطة + موقعك + السائقون القريبون + الأماكن المحفوظة (المنزل/العمل)
- تحديد الالتقاط والوجهة (بحث / من الخريطة / موقعي الحالي)
- تفاصيل الرحلة: مسافة، وقت، رسم الطريق، نوع المركبة، السعر المقترح
- العروض من السائقين مع الفرز (الأقل سعراً / الأقرب / الأعلى تقييماً)
- تتبع مباشر، رمز بدء الرحلة، اتصال، مشاركة، بلاغ، إلغاء بتأكيد
- التقييم، رحلاتي (مع إعادة الطلب)، المحفظة (طلب شحن)، الإشعارات، الدعم

## المكتبات
`flutter_map` `latlong2` `geolocator` `geocoding` `firebase_core` `firebase_auth` `firebase_database` `http` `url_launcher` `share_plus`

## التشغيل
المشروع يحتوي على كود Dart فقط؛ مجلدا `android/` و`ios/` يُولَّدان تلقائياً:
```bash
bash tool/setup_platforms.sh   # مرة واحدة (يضيف صلاحيات الموقع في Android وiOS)
flutter run
```
بناء APK: `flutter build apk --release` — أو ارفع المشروع على GitHub وسيبني **GitHub Actions** ملف APK تلقائياً (Actions ← Artifacts).

## الإعداد المطلوب في Firebase (مرة واحدة)
1. Authentication ← Sign-in method ← فعّل **Email/Password**.
2. Realtime Database ← Rules ← الصق محتوى `firebase/database.rules.json` من مشروع لوحة التحكم ثم Publish.
3. أضف تطبيق Android بالحزمة `com.sikka` (موجود لديك) — الإعدادات مضمّنة في `lib/firebase_options.dart`.

## التخصيص
`lib/core/config.dart`: مضبوط على مصر (الجنيه ج.م، رمز +20، مركز الخريطة القاهرة، البحث داخل مصر فقط). الأسعار الافتراضية: أساسي 15، الكيلو 5، حد أدنى 25 جنيه (تُعدَّل من لوحة التحكم). أرقام الموبايل المقبولة 010/011/012/015. يمكن تعديل مصدر البلاطات، نصف قطر السائقين القريبين.

## ملاحظات مهمة
- خوادم OSM/Nominatim/OSRM العامة للتجربة فقط؛ للإنتاج استخدم مزوداً مناسباً أو استضف الخدمات.
- رمز التحقق عبر SMS غير مفعّل (الدخول بالجوال + كلمة المرور). يمكن ربط مزود OTP لاحقاً.
- الدفع الحالي نقداً للسائق. الخصم التلقائي من المحفظة والإشعارات الفورية (FCM) والتحقق الصارم من الحالات يحتاجان Cloud Functions.
- لم أستطع تشغيل `flutter analyze` أو بناء التطبيق في بيئتي (بدون Flutter/إنترنت). شغّل `flutter analyze` أول مرة وأرسل لي أي خطأ يظهر لأصلحه.
