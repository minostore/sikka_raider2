# Sikka Driver — تطبيق السائق (Flutter: Android + iOS)

## الشاشات (حسب التصميم)
افتتاحية ← تسجيل الدخول (رقم الهاتف) ← تسجيل السائق (خطوات 1-2-3: البيانات، المركبة، المستندات) ← جارٍ التحقق من المستندات ← متاح للرحلات (خريطة + الطلبات القريبة) ← طلب رحلة جديد (قبول/رفض) ← تفاصيل الطلب ← قبول الرحلة وبدء التوجيه ← الوصول إلى الراكب ← الرحلة الحالية ← إنهاء الرحلة ← الأرباح ← سجل الرحلات ← التقييمات ← الملف والمركبة والإعدادات.

## مناطق الخدمة
لا يستطيع السائق الاتصال («متاح للرحلات») إذا كان موقعه الحالي خارج مناطق الخدمة التي ترسمها الإدارة، وتظهر له حدود المناطق على الخريطة.

## سياسة الموقع
غير متصل: لا شيء. متصل: موقع تقريبي كل 15 ثانية. أثناء رحلة: موقع دقيق كل 5 ثوانٍ يراه راكب الرحلة فقط وينتهي بانتهائها. التتبع يعمل والتطبيق مفتوح (Foreground).

## التشغيل
```bash
bash tool/setup_platforms.sh
flutter run
```
معرّف الحزمة: `com.sikka.driver`. مستندات السائق تُرفع إلى **Cloudflare R2** عبر خدمة `sikka-uploads` (مشروع منفصل)، وعنوانها يُضبط من لوحة التحكم ← الإعدادات (لا حاجة لإعادة بناء التطبيق).

## ملاحظات
رمز بدء الرحلة يُتحقق منه داخل التطبيق (للإنتاج الصارم انقله إلى Cloud Function). راجع ملاحظات تطبيق المستخدم.


## التحقق الحي من الوجه عند الاتصال (إضافة 2026-10-16)
- عند الضغط على «متصل»، تظهر الكاميرا الأمامية ولا يبدأ استقبال الرحلات قبل اجتياز تحدي حركة حيّ: إغلاق/فتح العينين ثم تحريك الرأس والعودة للأمام.
- بعد التحدي يلتقط التطبيق صورة جديدة مؤقتة ويرسلها إلى `/api/driver/online-face-verify` للمقارنة على الخادم مع صورة السيلفي المعتمدة في `drivers/{uid}/docs/photo`. الصورة الحية لا تُحفظ في Firebase أو R2.
- الخادم يصدر تصريح اتصال قصيرًا (45 ثانية) داخل `driverOnlineAuth/{uid}`، وقواعد Realtime Database تمنع الاتصال دون التصريح. يجب نشر `firebase/database.rules.json` من لوحة التحكم.
- هذا فحص حيوية عملي أساسي وليس ضمانًا مطلقًا ضد الفيديوهات/الهجمات المتقدمة؛ لا تستخدمه وحده كضمان أمني مطلق.
- إصلاح بناء Kotlin/Java: تم توحيد target إلى JVM 17 في `tool/patch_platforms.py` وخطوة GitHub Actions. أعد تشغيل Actions بعد رفع الملفات.
- المتطلبات: متغيرات AWS Rekognition وR2/Firebase في Vercel مضبوطة، `settings/adminApiUrl` يشير إلى خادم لوحة التحكم، وصورة `photo` المعتمدة محفوظة في R2.
